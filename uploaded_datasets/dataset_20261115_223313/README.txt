SYNTHETIC MEDICAL-STYLE IMAGE SAMPLES

This archive contains 20 artificially generated chest-radiograph-style images
for testing an image preprocessing pipeline:
grayscale conversion -> 28x28 resize -> tensor conversion -> normalization.

Included formats: JPG, JPEG, PNG, BMP, TIFF.

IMPORTANT:
- These are synthetic illustrations, not real patient images or clinical X-rays.
- They are not suitable for diagnosis, clinical validation, or claims about model accuracy.
- Use them only to test file loading and preprocessing compatibility.
